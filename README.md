# Имплантация зубов — центр «Подмосковье», Ярославль

Посадочная страница для медицинского центра «Подмосковье» (mc-podmoskovie.ru).

**Демо:** https://kapustina-ann.github.io/podmoskovie-implant/

## Что внутри

Один самодостаточный `index.html`. Шрифты (Roboto, Ubuntu), логотип, фотографии врачей
и все изображения зашиты в файл как data URI — внешних зависимостей нет, страницу можно
залить на любой хостинг как есть.

- Палитра и типографика — с сайта клиники: `#1fbbc7`, `#0096aa`, `#006977`, `#003c44`,
  `#e66b06`, `#be6f06`
- Светлая и тёмная темы
- Отзывы и рейтинги врачей — с сервиса ПроДокторов
- Слайдер отзывов на чистом JS, раскрывающиеся списки врачей — на `<details>`, без библиотек

## Блоки

Первый экран с формой → три направления → статус Nobel Biocare → цены → системы имплантов →
что входит в работу центра → этапы лечения → работы врачей → хирурги и ортопеды → отзывы →
частые вопросы → запись → контакты
